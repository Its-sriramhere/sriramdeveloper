# From Coast to Code

Optimized assets prepared from the owner's twelve chapter pages and expression sheet.
The raw 37 MB PNG set is kept outside the repository. `manifest.json` records the crops.
The reference expression containing sunglasses is excluded.

`chapter-*` are the complete supplied illustrated pages, including their printed lettering.
`world-*` and `detail-*` are separately framed scene crops. HTML supplies selectable narration.
`character-*` and `prop-*` are manually ink-masked transparent cutouts for independent motion.
Expressions are individual reference portraits. The small departure traveller uses a segmented
illustrated body and the supplied no-glasses face; it is separate from the original page art.

Reproduce with `node scripts/prepare-journey.cjs <chapter-directory> <expression-sheet>`.
