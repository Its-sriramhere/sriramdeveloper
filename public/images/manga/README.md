# The Quiet Build — original manga artwork

Eight original, standalone SVG illustrations created for this portfolio. The artwork uses vector ink lines, screentone patterns, Japanese-inspired settings, and a consistent fictional red-scarfed developer character. It contains no portrait photographs, external images, scripts, or third-party manga characters.

1. `01-the-request.svg`: a rain-soaked city request
2. `02-listen-first.svg`: discovery through a café conversation
3. `03-the-blueprint.svg`: mapping a build on paper
4. `04-the-interface.svg`: the first working interface
5. `05-the-hidden-system.svg`: the application behind the screen
6. `06-the-plot-twist.svg`: an unexpected debugging setback
7. `07-earn-the-ending.svg`: a testing montage
8. `08-a-new-morning.svg`: release and the next beginning

Each asset is 600 × 800 with a matching viewBox. Captions and dialogue remain HTML in `components/motion/MangaStory.tsx` for responsive reading and accessibility. The technical decisions describe a fictional narrative of an engineering workflow, not claims about a particular client project.
